# おひめさまの アトリエ

[ブラウザで遊ぶ](https://ryo-piyopiyo.github.io/princess-atelier/)

着せ替え、おめかし、絵地図でのおでかけができる水彩の遊びです。iPadではSafariで開き、最初の2枚の絵から好きなモードをタップしてください。ホーム画面にも追加できます。

写真は端末内で処理され、アプリから送信されません。ブラウザの設定には衣装や架空のおともだちを保存できますが、顔写真は保存しません。

案内の声：AivisSpeech: まお（[モデル](https://hub.aivis-project.com/aivm-models/a59cb814-0083-4369-8542-f51a29e72af7) ／ [ACML 1.0](https://github.com/Aivis-Project/ACML/blob/master/ACML-1.0.md)）。BGM「花びらのしたく」はこのアプリのために作ったオリジナルの器楽曲です。既存曲の録音や外部の音源サンプルは使っていません。保護者設定ではBGMだけをオフにできます。画像も本作用のオリジナル素材です。
